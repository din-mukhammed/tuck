# Tuck v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS menu bar app, Tuck, that hides menu bar items behind a toggle icon, with an always-hidden section, auto-hide, a Settings window and launch at login.

**Architecture:** Three `NSStatusItem`s (the Tuck icon and two dividers); a divider set to 10,000 pt pushes the items to its left off screen. A pure `VisibilityState` decides the divider widths; `MenuBarController` applies them. Built with plain `swiftc` from shell scripts.

**Tech Stack:** Swift 6.1 (Command Line Tools 16.4), AppKit, SwiftUI, ServiceManagement. No SwiftPM, no Xcode, no third-party code.

**Spec:** `docs/superpowers/specs/2026-11-02-tuck-design.md`

## Global Constraints

- Target `arm64-apple-macos13.0`; language mode Swift 5 (`-swift-version 5`) to avoid strict-concurrency churn in AppKit callbacks.
- Every `swiftc` call goes through `scripts/env.sh`, which adds `-vfsoverlay F -Xcc -ivfsoverlay -Xcc F` when `/Library/Developer/CommandLineTools/usr/include/swift/module.modulemap` and `bridging.modulemap` both exist (F maps the former to an empty file under `.build/`). Never edit `/Library`.
- `Sources/TuckCore` imports Foundation only (no AppKit), so it compiles into the test binary.
- Bundle id `dev.tuck.Tuck`, name `Tuck`, version `0.1.0`, `LSUIElement` true, `LSMinimumSystemVersion` `13.0`.
- Original branding only: the name Tuck, SF Symbols for icons, our own copy. Do not copy code from Ice or Hidden Bar.
- Divider lengths: expanded `10_000`, collapsed `8`. Auto-hide delay default `10` s, clamped to `2...60`. Defaults: auto-hide on, always-hidden section on.
- Status item `autosaveName`s: `tuck.toggle`, `tuck.hidden`, `tuck.always`.
- `.build/` and `dist/` are git-ignored. Commit after every task, message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. ⌥-click with the always-hidden section turned off must show only the hidden section (`shown`), never `allShown`. Test in Task 1.
2. Turning the always-hidden section off while in `allShown` must drop to `shown`. Test in Task 1 (`normalized`).
3. A delay stored outside `2...60` (hand-edited defaults) is clamped on read. Test in Task 2.
4. The timer firing while the pointer is in the menu bar must re-arm, not hide. Test in Task 2.
5. Launch at login failing (unsigned or misplaced bundle) must not crash and must show the error. Manual check in Task 4.

**Interfaces:**
- Consumes: `VisibilityState`, `DividerLength`, `autoHideAction`, `Preferences` (Tasks 1–2).
- Produces: `final class MenuBarController` with `init(preferences: Preferences, openSettings: @escaping () -> Void)`; `AppDelegate` holds the `Preferences`, the controller, and (Task 4) the settings window.

- [ ] **Step 1: `main.swift`**: `NSApplication.shared`, set delegate, `.setActivationPolicy(.accessory)`, `run()`.
- [ ] **Step 2: `MenuBarController`.**
  - Create items in this order so they sit right to left: toggle (`tuck.toggle`, `variableLength`), hidden divider (`tuck.hidden`), always divider (`tuck.always`, created only while `alwaysHiddenEnabled`; removed with `NSStatusBar.system.removeStatusItem` when turned off).
  - Toggle icon: SF Symbol `chevron.compact.left` when hidden, `chevron.compact.right` when shown, `isTemplate = true`, accessibility label "Tuck".
  - Dividers: SF Symbol `poweron` (a thin vertical bar) at alpha 0.5, template; length = `DividerLength.expanded` when the state says expanded, else `.collapsed`; the image is cleared while expanded.
  - The toggle button `sendAction(on: [.leftMouseUp, .rightMouseUp])`; in the action read `NSApp.currentEvent`: right-click or ⌃-click opens a menu (Settings… → `openSettings`, separator, "Quit Tuck" ⌘Q) via `NSMenu.popUp(positioning:at:in:)` on the button; otherwise `state = state.clicked(option: modifierFlags.contains(.option), alwaysHiddenEnabled:)` and apply.
  - Auto-hide: on entering `shown`/`allShown`, schedule a one-shot `Timer` for `preferences.autoHideDelay`; on fire, compute `autoHideAction(state:enabled:pointerInMenuBar:)`, where `pointerInMenuBar` = `NSEvent.mouseLocation` inside the top `NSStatusBar.system.thickness` points of the screen containing it; `.hide` → state `.hidden`, `.rearm` → schedule again. Cancel the timer on `.hidden`.
  - Subscribe to `preferences.$alwaysHiddenEnabled` (Combine): add/remove the always divider and set `state = state.normalized(...)`.
